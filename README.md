## Descripción breve del programa
Este programa consiste en un sistema de pedidos para una cafetería, desarrollado en C# utilizando Windows Forms. Permite registrar los datos del cliente, introducir los productos y sus precios, y calcular el costo total del pedido según las opciones seleccionadas.

## Datos de entrada
- Nombre del cliente.
- Fecha del pedido.
- Tipo de cliente (frecuente o no frecuente).
- Nombre del producto.
- Precio digitado.
- Tamaño del producto.
- Selección de porción extra.

## Proceso
1. Registrar los datos del cliente y la fecha del pedido.
2. Introducir el nombre y el precio del producto.
3. Verificar el tamaño seleccionado y agregar RD$25 si es grande.
4. Verificar si el cliente solicita una porción extra y aplicar el costo correspondiente.
5. Calcular el precio unitario y el total del pedido.

## Datos de salida
- Información del cliente.
- Fecha del pedido.
- Producto seleccionado.
- Precio unitario calculado.
- Total a pagar por el pedido.
